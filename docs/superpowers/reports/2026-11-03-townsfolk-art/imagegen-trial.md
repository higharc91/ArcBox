# Mother Aubrine — alternative pixel-art trial

The owner requested using the assistant image tool instead of PixelLab for the next
character. Mother Aubrine’s approved Scenario concept was reused for identity,
with approved Bree/Halden sprites supplying pixel style. One new review candidate
was generated with `image_gen.imagegen`; no PixelLab calls or credit spend.

Assets and measured limitations: [candidate record](../../../../tools/tactics-assets/imagegen/townsfolk/mother-aubrine/README.md).
The image is displayed in chat for owner appearance review. It is not an approved
or usable eight-direction runtime atlas: facing consistency, alpha, native pixel
grid and scale require correction/validation. Production remains at the approved
Bree/Halden checkpoint; no gameplay/phone changes. No code tests are needed for
this review-only PNG/documentation addition. Do not install before art approval
and complete production validations. No PR or merge.

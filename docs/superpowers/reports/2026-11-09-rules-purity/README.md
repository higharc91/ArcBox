# Rules purity boundary — #200

The battle core keeps its existing deterministic state/command API. All physical file acquisition has moved behind `ArcBox.Sdk.Content.IFileSource`, whose default `PhysicalFileSource` implementation is outside the Logic assembly. Rules-pack, art and lore loading accept an injected source, including lazy voice-clip duration reads and side-content validation. Existing public entry points and method-group signatures remain available. There is no mutable process-wide file-source override. Content loading is explicitly an effectful operation; the README now states the narrower, accurate claim that battle application and planning are pure with respect to supplied state/content.

`BannedSymbols.txt` is included as an AdditionalFile in the Logic build. Microsoft.CodeAnalysis.BannedApiAnalyzers 3.3.4 is pinned and private to that project. With the repository's warnings-as-errors policy, direct File/Directory/FileInfo/DirectoryInfo/FileStream/StreamReader/StreamWriter calls, machine-time properties, System.Random, GUID generation, Stopwatch and cryptographic ambient randomness fail compilation. Path manipulation, parsing supplied memory/streams, and existing IO-error reporting remain available.

Four focused tests pass: no Game/Presentation/Godot assembly reference, ordered state collection types (including the `ImmutableSortedDictionary<UnitId, UnitState>` contract behind unit iteration), rules/art loading entirely from a virtual source, and lore plus lazy cached clip measurement from the injected source. The original loader, replay and story suites remain in the full gate.

A separate temporary compile-only probe referenced the project's actual banned-symbol file and tried DateTime.Now, DateTimeOffset.UtcNow, Random, Guid.NewGuid, File.Exists and Directory.GetDirectories. The build failed with six RS0030 errors, one for each operation; none was executed. A normal Logic Release build passed with zero warnings/errors. Full repository results are recorded in the PR before merge. No gameplay, content, art, voices, CI configuration or user files change.

# Shared spell contracts — #123

All 46 spell names shared by the player-class files now have the same mechanical definition across their class versions: tier, action/bonus/reaction cost, targeting, area, friendly fire, damage/healing, saves, conditions and duration. The comparison uses loaded typed definitions, so different JSON spellings of the same dice/save are not mistaken for gameplay differences. Each class retains its ability IDs, presentation/FX IDs, flavour, animation and AI hints. Inline zone-passive IDs retain their class namespace.

The existing wizard version is the mechanical baseline for arcane spells, cleric for shared healing/restoration, and ranger for the two shared nature-zone/ward spells. These are the game's existing tactical adaptations, not a claim that every range/area or damage ladder reproduces tabletop SRD. Hypnotic Pattern consistently applies both Charmed and Incapacitated and permits friendly fire. Cure Wounds is 2d8, Healing Word 2d4 and Mass Cure Wounds 5d8 for druids, with the same casting-stat bonus and self-target support as other classes. Barkskin consistently uses the ranger's bonus-action, non-concentration battle ward; Spike Growth uses ten rounds; Greater Invisibility uses ten rounds. Lesser Restoration consistently removes poison, blindness and paralysis with a bonus action. Shared area spells no longer silently spare allies for selected classes.

Resource names remain class-specific. The seven explicit pact-slot cost adaptations in `contracts.json` preserve the Warlock's small slot pool; tests assert their exact values rather than blanket-ignoring resource costs. Other resource amounts match the shared tier/cost, including Lore Counterspell. `contracts.json` lists every canonical version. `changes.json` records the complete before/after data for all 37 changed abilities, including changes beyond the issue examples such as cantrip scaling, Dispel Magic and Greater Restoration. No art, voices, encounter placements, starting kits or class resource pools change.

Regression checks: the shared-spell test dynamically discovers all duplicated spell names and compares every mechanical field; a new unrecorded difference fails. Separate cases assert druid healing dice at all ten levels and friendly-fire consistency for Shatter, Thunderwave and Hypnotic Pattern. All seven new cases and all six existing content-ladder cases pass. Full repository validation is recorded in the PR before merge. These corrections intentionally change the affected class spell effects; detailed balance sweeps are tracked separately by #119/#118/#121 rather than claimed from unit tests.

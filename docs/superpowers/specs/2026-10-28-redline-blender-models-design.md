# REDLINE Blender Model Polish — Design Spec

- **Date:** 2026-10-28
- **Status:** Approved in conversation
- **Builds on:** [REDLINE design](2026-10-25-redline-design.md) §4.8, [podium design](2026-10-28-redline-podium-design.md)

## 1. Purpose
Replace the procedural C# meshes with higher-quality models built in Blender, and make the 22 drivers recognisable as the real drivers.

### Decisions made by the user
| Topic | Decision |
|---|---|
| Driver likeness | **Include face likenesses** (in addition to suits, caps, helmets, numbers, flags, build). Private game only; no logos. This supersedes the REDLINE spec's "no driver likenesses" out-of-scope line for this private build. |
| Tooling | **Headless Blender in the cloud container** (Ubuntu `blender` 4.0.2), models built by committed Python (`bpy`) scripts and exported as `.glb`. (The Blender MCP isn't connected here; the scripts do what the MCP would.) |
| Scope | **Cars, drivers and helmets, podium set, circuit landmarks.** |

### Constraints
- **No logos or trademarks:** no team, sponsor, series or helmet-sponsor logos; no real helmet artwork copied line for line — colour schemes and broad motifs only.
- **Likenesses are respectful and public-trait-based:** height and build, skin tone, hair colour/texture/style, facial hair, face shape, eye colour, from widely known public appearance. Stylised-realistic, not caricature for mockery. Uncertain traits are marked `"confidence": "low"` in the data so the user can correct them.
- **Reproducible:** every asset is generated by `tools/blender/build.py` from scripts + data; the `.glb` outputs are committed so the TV app needs no Blender.
- **Single source for liveries:** car paint colours still come from `games/Redline/Redline.Logic/Data/grid2026.json` at runtime; the car `.glb` exposes named material slots instead of baked colours.
- **Budgets (RTX 5080, 1440p @ 144 fps):** car ≤ 120k triangles (LOD1 ≤ 30k), driver figure ≤ 40k, helmet ≤ 12k, podium set ≤ 150k, landmarks ≤ 600k total. Repo size of all `.glb` ≤ 40 MB.
- **Fallback:** if a `.glb` is missing or fails to load, the TV uses the existing procedural mesh (no regression).

## 2. Pipeline
```
tools/blender/
  build.py            # entry: blender -b --factory-startup -P tools/blender/build.py -- [--only cars|drivers|podium|landmarks] [--preview]
  lib/                # common: materials, bevel/subdiv helpers, naming, glTF export, preview render, validation
  car.py helmet.py driver.py podium.py landmarks.py
  data/drivers.json   # per-driver traits (likeness, build, helmet scheme)
  check.py            # validates every exported .glb: triangle budgets, material/node names, dimensions
src/ArcBox.Host/games/redline/models/
  car_2026.glb  car_2026_lod1.glb
  drivers/<CODE>.glb  helmets/<CODE>.glb
  podium.glb  landmarks/*.glb
```
- Units metres, +Y up in Godot (glTF exporter converts from Blender Z-up), car origin on the ground midway between the axles, +Z forward in Godot — matching `CarMeshBuilder` so placement code is unchanged.
- **Named material slots** (Godot binds them): car `paint_top`, `paint_side`, `stripe`, `nose`, `wing`, `endplate`, `halo`, `carbon`, `tyre`, `tyre_stripe`, `rim`, `light`, `glass`; driver `skin`, `hair`, `suit_primary`, `suit_secondary`, `cap`, `eyes`; helmet `helmet_base`, `helmet_a`, `helmet_b`, `visor`.
- **Number decals** stay Godot `Label3D` at named empties: `number_nose`, `number_endplate_l`, `number_endplate_r` (car), `number_suit` (driver).
- A C# test (no Blender) parses each committed `.glb` (glTF JSON chunk) and asserts required node and material names exist, so a broken export fails `dotnet test`.

## 3. Models
- **Car (2026 regs):** smooth subdivided monocoque, nose, sidepods with undercut, engine cover with shark fin, halo, front and rear wings with endplates and active-aero flaps, floor with edges and diffuser strakes, suspension (wishbones, push/pull rods), mirrors, T-cam, rain lights, wheels with rim spokes and wheel covers, tyres with shoulder and compound stripe (no text). Bevels on all hard edges; materials: metallic-flake paint (clearcoat), matte paint option, carbon weave (procedural normal), rubber, brushed rim. Panel lines as shallow insets.
- **Helmet (per driver):** 2026-style shell with visor, visor strip and spoiler; design = base colour + up to two accent colours in one of a small set of motif patterns (stripes, chevrons, halves, flag-inspired bands, swirls) that approximates the real helmet's scheme.
- **Driver figure (per driver):** proportioned body at the driver's height and build in a team-colour race suit (two-tone, belt, number on chest, name tag, nationality flag patch on the shoulder), team-colour cap on the podium, holding a champagne bottle (separate node `bottle` attached to `hand_r`). Simple rig: `spine`, `arm_r`, `hand_r` empties so Godot can animate the spray pose (raise arm).
  - **Face:** parametric head (face width, jaw, chin, cheekbones, brow, nose length/width, eye spacing, ears) + skin tone + eye colour + eyebrows; hair as sculpted shells or hair cards by style (short crop, textured crop, swept, curly, coiled, locs/braids, buzz, longer top); facial hair (stubble shading, beard, moustache).
- **Podium set:** stepped blocks with numerals, backdrop frame with light bars, branded panels (REDLINE/ARCBOX only), stairs, bottle stands, confetti cannons.
- **Landmarks:** main grandstand with roof and seats, pit building with garages, start gantry with five-light pods, Turn 1 grandstand, Observation Tower with its red canopy, corner grandstands, generic trees (live oak) as 2–3 variants.

## 4. Godot integration
- `ModelLibrary` (Godot side) loads `.glb` scenes once (background), with the procedural builders as fallback.
- `CarFactory` uses `car_2026.glb` (+ LOD1 by distance via `visibility_range`), binds team colours to the named materials, attaches the driver's helmet at the `helmet` empty.
- Podium uses `drivers/<CODE>.glb` for the three podium figures; the spray pose rotates `arm_r`.
- WorldBuilder swaps landmarks to the `.glb` versions.
- Render presets unchanged; Low preset uses LOD1 cars.

## 5. Testing
- `tools/blender/check.py` (run in Blender) validates budgets, names and dimensions for every export.
- `dotnet test`: glb header/name checks; `CarFactory`/`ModelLibrary` fallback logic in testable C# where possible.
- Preview renders (Godot `--redline-demo` screenshots: grid, close trackside, podium) reviewed against the previous procedural shots; driver close-ups for each of the 22 drivers in a contact sheet for the user to judge the likenesses.

# Hooded Stranger portrait

`hooded-stranger-portrait.png` is the 40×40 transparent portrait made in Scenario
with Retro Diffusion Plus (`model_retrodiffusion-plus`), asset
`asset_Wsn8STXMPF56bHUVQY35Ujv3`. It used the masked-traveler concept
`asset_PkDZrEL7XkvM1QNy3f1aJUwZ` and the refined bust
`asset_g22tmBiRChZ7xfHrxPhR9bE7` as visual references, at seed 26501.

The portrait generator composites this image over the neutral backdrop for all
six dialogue moods. The opaque mask intentionally has no visible expression.
The layered game sprite uses a matching mask and hood so animation and palette
changes still work.
